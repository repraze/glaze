`TextureCoordinateTest.glb` is unmodified. Two files are derived from it for the OBJ demo (CC0 allows this):

- `TextureCoordinateTest.obj`: the four textured quads (not the untextured back plane), positions, normals and UVs, with `vt` written in the OBJ convention (v up, so `v = 1 - v`).
- `TextureCoordinateTest.png`: the GLB's embedded base color image, extracted byte for byte.
